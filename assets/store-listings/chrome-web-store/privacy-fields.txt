SINGLE PURPOSE DESCRIPTION
KeyMove provides keyboard-first search and navigation within web pages, helping users find visible text, select passages, and operate links and controls without using a mouse.

HOST PERMISSION JUSTIFICATION (*://*/*)
KeyMove needs access to ordinary HTTP and HTTPS pages because its search and keyboard navigation work on whichever website the user is visiting. It reads rendered page text and control labels locally to find matches, displays its search interface and highlights, and selects or activates the result chosen by the user. Its child-frame helper provides the same functionality inside eligible embedded frames. Limiting access to a fixed list of websites would prevent this core feature from working on other sites. Page content and search queries are not sent to the developer or to an external service.

SCRIPTING JUSTIFICATION
KeyMove uses chrome.scripting to inject its packaged content script, child-frame helper, and highlight stylesheet into eligible tabs that were already open when the extension was installed. This makes search available immediately without requiring those pages to be reloaded. Every injected file is included in the extension package; the extension does not download executable code.

STORAGE JUSTIFICATION
KeyMove uses chrome.storage.local to save the user's preferences, including theme, activation shortcut, per-site activation and pause rules, search-bar position and width, suggestion count, and highlight settings. These settings remain in the user's browser. Search queries and searched page content are not saved in extension storage or sent to a server.
