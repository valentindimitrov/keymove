# Website fonts

Unmodified Google Fonts WOFF2 subsets, downloaded 2026-10-08 from the Google Fonts CSS API:

https://fonts.googleapis.com/css2?family=DM+Sans:wght@400..700&family=Manrope:wght@400..800&display=swap

- DM Sans v17: Latin and Latin Extended, variable weights 400–700.
- Manrope v20: Latin and Latin Extended, variable weights 400–800.

Both fonts use the SIL Open Font License 1.1. Copyright notices and licenses are preserved
in `DM-Sans-OFL.txt` and `Manrope-OFL.txt`, sourced from the corresponding `ofl/dmsans`
and `ofl/manrope` directories in https://github.com/google/fonts. The website build appends
both notices to its downloadable `LICENSE.txt`; the extension license file is unchanged.

The fonts are served locally with `font-display: swap`, without a Google Fonts request.
